CAPWORDS — FIRST RUN
Loading screen and onboarding flow
The launch screen is the buddy waking up: one sprite, one segmented meter, one line of copy that changes as the app boots. Onboarding then asks for exactly the four things the app cannot start without — language, species, name, daily goal — and ends on the camera primer, because the first real action is a photo.
1a
Loading — three moments of the same screen
Nothing moves position between frames. The meter fills, the buddy wakes, the caption changes. If loading finishes in under a second the user only ever sees the last frame, which is why it also reads as a static splash.
